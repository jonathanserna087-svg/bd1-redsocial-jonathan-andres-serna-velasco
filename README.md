# Red Social Estudiantil

## Nombre del proyecto
Red Social Estudiantil: diseño de la base de datos (Bases de Datos I).

## Integrantes
- Jonathan Andrés Serna Velasco

## Descripción del caso
Esta plataforma pensada para mejorar la comunicación y la interacción entre nosotros los estudiantes de la universidad. Que nos permite crear perfiles (área de estudio, intereses y habilidades), conectar y seguir a otros estudiantes, publicar preguntas, recursos y novedades, crear y unirse a grupos de estudio o de interés, y programar eventos. Este repositorio contiene el diseño de la base de datos que soporta esta red social.

## Contenido del repositorio
- `Tarea1/`: entrega de la Tarea 1 (modelo conceptual).
- `Tarea2/informe/`: informe en PDF con el modelo lógico normalizado, el diccionario de datos y el diagrama.
