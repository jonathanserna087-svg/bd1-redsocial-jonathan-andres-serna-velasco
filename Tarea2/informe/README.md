# Tarea 2 · Informe: Modelo lógico y diccionario de datos

**Proyecto:** Red Social Estudiantil (Bases de Datos I)
**Autor:** Jonathan Andrés Serna Velasco

## Contenido de esta carpeta
- `Tarea2_Informe_ModeloLogico_RedSocialEstudiantil.pdf`: informe completo con el paso a paso de la propuesta de solución.

## Qué incluye el informe
1. Referencia al modelo conceptual (MER) aprobado en la Tarea 1.
2. Proceso de normalización aplicado (1FN, 2FN y 3FN).
3. Correspondencia entre las entidades del modelo conceptual y las tablas del modelo lógico.
4. Explicación de las decisiones de nombres y de la conversión de entidad a tabla.
5. Diccionario de datos: una tabla descriptiva por cada una de las 24 tablas (atributo, tipo de dato y longitud, descripción y justificación).
6. Descripción de cada relación (cardinalidad e implementación lógica).
7. Diagrama del modelo lógico.
8. Conclusión individual.
